# Scientific Calculator

## About the Project

This is a Scientific Calculator developed using HTML, CSS, and JavaScript. The project is designed to perform both basic and advanced mathematical calculations through an easy-to-use interface.

The calculator supports arithmetic operations, trigonometric functions, logarithmic functions, powers, roots, memory functions, mathematical constants, and angle mode conversion between radians and degrees.

## Features

Basic arithmetic calculations such as addition, subtraction, multiplication, and division.

Scientific functions including sine, cosine, tangent, hyperbolic functions, logarithms, exponents, powers, square roots, and reciprocals.

Memory operations such as MC, MR, M+, M-, and MS.

Support for mathematical constants like π, e, φ, and i.

RAD and DEG mode switching for trigonometric calculations.

Adjustable precision for calculation results.

Copy result functionality.

Interactive function glossary for understanding calculator operations.

Modern and responsive user interface.
