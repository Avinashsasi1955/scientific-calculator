Function Glossary
0 - 9 Numeric Keys: Inserts integer digits into your expression.
. Decimal Separator: Places a fractional point to build decimals.
+ Addition: Calculates the sum of preceding and succeeding values.
− Subtraction: Evaluates difference between values.
× Multiplication: Finds the scaling product of two expressions.
÷ Division: Computes fraction quotient. Warns on division by 0.
= Evaluate: Processes mathematical expression, displays result and logs to history.
AC All Clear: Resets calculator state, display result, and current formula.
⌫ Backspace: Safely deletes the last numeric character or function token.
( ) Parentheses: Organizes nested sub-equations and controls evaluation priority.
2nd Shift / Secondary: Swaps primary keys for inverses (e.g. sin ➔ sin⁻¹, x² ➔ x³).
RAD / DEG Angle Mode: Toggles standard trigonometry calculations between Radians & Degrees.
Audio Toggle: Toggles Web Audio synthesized haptic key-click feedback on/off.
Calculation Log: Toggles calculation drawer showing previous formulas and inputs.
Copy Copy Output: Copies the main result display contents to the computer clipboard.
Precision Decimal Rounding: Configures maximum output digits (4, 8, 12, or 16) to display.
MC Memory Clear: Resets the stored value in internal memory back to 0.
MR Memory Recall: Retrieves stored memory value and appends it to the equation.
M+ Memory Add: Adds the current output display value directly to memory storage.
M- Memory Subtract: Subtracts display value from stored memory value.
MS Memory Store: Directly saves current display output into memory storage.
sin / sin⁻¹ Sine / Arcsine: Standard or inverse trigonometric ratios of the angle.
cos / cos⁻¹ Cosine / Arccosine: Horizontal ratio relative to unit circle.
tan / tan⁻¹ Tangent / Arctangent: Slope ratio of opposite over adjacent side.
sinh Hyperbolic Sine: Calculates (ex − e−x) / 2 exponential curve.
cosh Hyperbolic Cosine: Calculates (ex + e−x) / 2 catenary shape.
tanh Hyperbolic Tangent: Calculates hyperbolic ratio sinh(x) / cosh(x).
ln Natural Logarithm: Logarithm base e. Solves ey = x.
log Common Logarithm: Logarithm base 10. Solves 10y = x.
log₂ Binary Logarithm: Logarithm base 2. Solves 2y = x.
x² / x³ Power of 2 / 3: Multiplies a value by itself twice or three times.
xʸ / ʸ√x Custom Exponent / Root: Raises base x to power y, or y-th root.
√ / ∛ Square / Cube Root: Finds value that squared or cubed equals x.
EXP Scientific Notation: Appends *10^ to enter values in engineering format.
10ˣ / eˣ Exponentials: Raises constant 10 or Euler's number e to power x.
1/x Reciprocal: Divides 1 by current number (x ➔ x−1).
π Pi (~3.14159): Fundamental circle circumference constant.
e Euler's Constant (~2.71828): Growth factor exponential base.
φ Golden Ratio (~1.61803): Geometric proportional constant.
i Imaginary Unit: Square root of negative number unit (i² = -1).
x! Factorial: Multiplies integer by every positive integer below it.
nCr Combinations: Selections of size r from population n where order is ignored.
nPr Permutations: Selections of size r from population n where order matters.
% Percentage: Divides value by 100 to make percentage calculations.
mod Modulo Remainder: Divides values and returns remainder of integer division.
abs / sign Absolute Value: strips signs. sign() yields −1, 0, or 1.
RAND / RndInt Randomizer: Creates random decimal [0,1) or integer between bounds.
round Rounding: Rounds floating values to the nearest integer.
gcd(x, y) Greatest Common Divisor: Finds the largest integer that divides both input integers.
lcm(x, y) Least Common Multiple: Computes smallest positive integer divisible by inputs.
isPrime(x) Primality Check: Returns true if integer has no factors but 1 and itself.
mean(a,b,...) Mean Average: Calculates total sum of inputs divided by argument count.
std(a,b,...) Standard Deviation: Calculates sample standard deviation dispersion index.
log(x, b) Custom Log Base: Evaluates logarithm of value x with respect to custom base b.
